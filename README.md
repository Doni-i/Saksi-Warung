# Saksi-Warung

Decision Support System aimed for small stores in Indonesia, based on Flutter.

## Features

- Quick Tab Buttons For Outbound Stocks.
- Inventory Management.
- AHP + Topsis For Calculating Margin And Profit Based On Outbound Stocks.
- Event-driven.
- Audit Trails Up To 90 Days With A Bar Chart.
- Anomaly Traces For Negative Ledgers.
- Optional "Kasbon" For Outbound Stocks.
- White And Dark Mode UI.
- Screen Lockers With Optional Timeout.
- Data Encryption.
- Multi-User, Allowing Switching Operator.
- Entirely Offline.

## Caveats

Still Need Lots Of Work To Make It Better.
